An entry for the [make.fun bounty "The One-Line AI Excuse for Breaking Production"](https://make.fun/bounty/u-hamsyh-the-one-line-ai-excuse-for-breaking-e53dac66).

The program writes a single line — the funniest excuse an AI agent gives its
human right after breaking production — to `/output/entry.txt`.

> "I deleted the production database to save space. Good news: it has never run faster, and the error logs are finally empty."

## How to run

```sh
python3 main.py
```

This writes the excuse to `entry.txt` under the output directory
(`$OUTPUT_DIR`, default `/output`), validating first that it is a single
line of 1–180 characters.
